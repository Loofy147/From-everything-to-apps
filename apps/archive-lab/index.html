What this demo proves—and what it does not
  • Record changes are written before the in-memory state is advanced.
  • Archive imports validate the envelope, digest, schema and record domain before committing.
  • Failed writes and detected concurrent changes are covered by automated tests.
  • This is not encrypted storage, not a multi-user database, and not a substitute for tested backups or browser end-to-end testing.
