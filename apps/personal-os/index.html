IMPLEMENTATION GATES

Build in this order

Every layer should solve a real personal workflow, not just add infrastructure.

01In place

Personal app shell

App launcher, searchable connector catalog, safe personal shortcuts and a roadmap.

Current PR · static preview target
02Next

Identity & permissions

Dedicated identity boundary, local/remote session contract, scoped grants, secret isolation and least privilege.

Before any cloud sync
03Next

Persistent shared data

Portable Postgres schema and migration path, owner-scoped records, versioned archive, tested recovery.

Compare Supabase, Neon and self-hosted alternatives
04Later

Workflow and AI adapters

Idempotent jobs, event log, optional Activepieces/n8n/Flowise services, and explicit per-tool authorization.

Keep services separable
05Later

Personal app portfolio

Notes/knowledge, tasks/project board, file workspace, research, media workbench and service desk.

Promote only after complete workflows are tested
06Later

Backup, monitoring and release gates

External backup restoration, error telemetry with consent, dependency/license inventory and rollback.

Before using important data
✓
Independence rule

Prefer standard formats and protocols (HTTP/OAuth, JSON, PostgreSQL, OpenAPI, webhooks). Vendor SDKs stay behind interfaces so each provider can be replaced without rewriting app domain logic.
